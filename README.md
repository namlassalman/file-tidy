# file-tidy

Background:
In this day and age with costs going out of control and cloud hardware costs increasing, users want a better way to manage files on their;

1. Mobile Phones
2. Cloud Storage
3. Desktops
4. Network Attached Storage

This is a project (not yet a product) to:

1. Connect to a folder also asking the user beforehand if there are any folders they do not want included in the search
2. Provide some basic information around;
   Count of files by file type and size on a single chart
   Information on deeply nested folders that could be better optimised
   
   
4. Ask the user which folders they want to scan with a rough estimate of how long it will take to scan the folder based on nesting levels and file/folder count
5. Provide recommendations on ways to save space and
6. If needed, apply those recommendations with the user approval
